# Screenshots

Place your screenshot of the program running in the terminal here named:
`program_output.png`

To capture:
1. Run `python src/analyzer.py` in your terminal.
2. Choose Option 5 (Key Insights) or Option 4 (Distributions).
3. Take a screenshot using `Win + Shift + S` (Windows) and save it as `program_output.png` inside this folder.
